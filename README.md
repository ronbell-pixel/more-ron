# More Ron

> More Ron is better than less Ron.

A one-page static site: hero photo, live St. Charles County, MO weather
(from [Open-Meteo](https://open-meteo.com), no API key needed) and a games section.

## Files

- `index.html` — the whole page (HTML, CSS and JS in one file)
- `ron.jpg` — hero photo

## Adding a game

In `index.html`, find the comment `To add a game` in the Games section, copy the
`<a class="card game">` block below it, and change the link, emoji and text.

## Hosting

The site is plain static files, so it runs on GitHub Pages:
**Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**.
